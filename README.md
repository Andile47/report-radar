# Report Radar

Report Radar is a dashboard that helps a municipality see **when** citizen reports are likely to surge and **where** problems are concentrated. Citizens report issues such as potholes, water outages and load-shedding faults. The dashboard turns those reports into a forecast, a hotspot map and a searchable list, so teams can plan their workload before the surge arrives.

## What the dashboard does

- **Headline numbers:** total reports, average urgency, and how many reports are high urgency (4 to 5).
- **Forecast tab:** shows weekly report volume, with the actual numbers and the predicted next few weeks on one chart, so you can see the projected workload.
- **Hotspots tab:** shows a map of the areas with the most reports, next to a ranked list of those areas from busiest to quietest.
- **Reports tab:** lists every report with its category, urgency score, area and description.
- **Filters:** choose one or more categories (water, roads, electricity, waste) and set a minimum urgency. The headline numbers and the reports list update to match.
- **Placeholder mode:** if any data file is not ready yet, the dashboard shows clearly labelled sample data for that part, so it always runs. Real data replaces it automatically once the file exists.

## Note on data

All data in this project is synthetic. No real personal information is used.
