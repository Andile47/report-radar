# Report Radar Brand

**Name:** Report Radar

## Chosen tagline

**Know where needs are rising.**

## Options considered

- See the signal. Plan the response.
- From resident reports to ready teams.

## Colour palette

| Use | Colour | Hex |
| --- | --- | --- |
| Main blue | Blue | `#0A21C0` |
| Accent | Coral | `#E4572E` |
| Accent | Amber | `#F2A33A` |
| Supporting text | Ink | `#141619` |
| Supporting status | Green | `#2E9E6B` |
| Muted text | Muted grey | `#5A5D6E` |
| Dividers | Light grey | `#DADBE6` |

The main blue and accents match the dashboard palette in `dashboard/app.py`.

## Type

Use **DM Sans** for headings and body text. It is clear at presentation size and available in Canva's free editor and Google Fonts. Use bold for headings and regular for body copy; keep slides uncluttered.

## Simple logo idea

In Canva Free, add a solid map-pin icon beside **Report Radar** in DM Sans. Make the pin blue and add one small coral dot inside it. Search Canva Elements for a free "map pin" icon; keep the design to these two pieces.
